# Footware 

A full-stack MERN ecommerce application.

## Features
- User Authentication
- Admin Dashboard
- Product Management
- Cart & Wishlist
- Orders
- Payment Integration
- Reviews & Ratings

## Tech Stack

### Frontend
- React.js
- Vite
- React Router
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Installation

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
npm install
npm start
```

## Environment Variables

Create a `.env` file and add:

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
CLOUDINARY_CLOUD_NAME=your_cloud_name
```
